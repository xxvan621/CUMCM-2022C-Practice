
区分度≠现实重要性

这也是熵权法最大的局限之一。

因此国赛论文里，如果你发现熵权法算出来某个指标权重特别夸张，**不要无脑接受结果**。你需要检查数据、标准化方式以及这个权重是否符合问题含义；必要时可以用 **AHP + 熵权法组合赋权**，或者做一个**权重敏感性分析**。



# **熵权法（Entropy Weight Method）**

## **1. 熵权法解决什么问题？**

熵权法是一种**客观赋权方法**。

核心思想：

**某个指标在不同评价对象之间的差异越大，它提供的区分信息越多，因此给予更大的权重。**

注意：

**区分度高 ≠ 现实中更重要。**

熵权法衡量的是**数据本身提供的信息量**，而不是人为认为某指标有多重要。

---

# **2. 首先定义** i **和** j

假设：

- 一共有 n 个**评价对象**
- 一共有 m 个**评价指标**

规定：

\boxed{i=\text{第几个评价对象}}

\boxed{j=\text{第几个评价指标}}

因此：

i=1,2,\dots,n

j=1,2,\dots,m

例如评价 3 个城市：
所以：

- i=2,j=1：上海的医疗水平
- i=3,j=2：广州的教育水平
- i=1,j=3：深圳的交通水平

一句话记忆：

i **看行 → 对象；**j **看列 → 指标。**

# **3. Step 1：原始数据** X

原始数据矩阵：

X=(x_{ij})_{n\times m}

其中：

\boxed{x_{ij}=\text{第 }i\text{ 个对象在第 }j\text{ 个指标上的原始数据}}

例如：

x_{21}=95

意思就是：

第 2 个城市（上海）在第 1 个指标（医疗）上的值是 95。

---

# **4. Step 2：指标正向化 + 标准化**

在正式计算熵权之前，通常需要先处理数据。

因为有些指标：

- 越大越好：收入、医疗水平、绿化率
- 越小越好：污染程度、死亡率、成本

需要先把它们统一成：

\boxed{\text{数值越大 = 表现越好}}

然后进行标准化，得到：

z_{ij}

因此：

\boxed{z_{ij}=\text{第 }i\text{ 个对象在第 }j\text{ 个指标上的标准化值}}

这样可以消除“万元”“百分比”“人数”等不同单位带来的影响。

---

# **5. Step 3：计算比例** P

对于**每一个指标** j，计算每个对象 i 占这一指标总量的比例：

\boxed{ p_{ij} = \frac{z_{ij}} {\displaystyle\sum_{i=1}^{n}z_{ij}} }

这里一定要看懂分母：

\sum_{i=1}^{n}z_{ij}

j 没有变化，i 在变化。

所以意思是：

**固定第** j **个指标，把所有评价对象在这个指标上的数值加起来。**

例如医疗水平：

z_{11}=90,\quad z_{21}=60,\quad z_{31}=30

那么：

p_{11}=\frac{90}{90+60+30}=0.5

p_{21}=\frac{60}{90+60+30}=0.333

p_{31}=\frac{30}{90+60+30}=0.167

所以：

\boxed{ p_{ij}= \text{对象 }i\text{ 在指标 }j\text{ 中所占的比例} }

并且对于任何一个指标 j：

\boxed{ \sum_{i=1}^{n}p_{ij}=1 }

---

# **6. Step 4：计算熵值** E

第 j 个指标的熵值：

\boxed{ e_j = -\frac{1}{\ln n} \sum_{i=1}^{n} p_{ij}\ln(p_{ij}) }

其中：

- e_j：**第** j **个指标的熵值**
- n：**评价对象数量**
- p_{ij}：对象 i 在指标 j 中的比例
- \ln：自然对数
- \sum_{i=1}^{n}：把所有对象加起来

注意这里最终得到的是：

\boxed{e_j}

而不是 e_{ij}。

因为我们最终要评价的是：

**第** j **个指标整体上有没有区分能力。**

---

## **熵值** e_j **怎么理解？**

如果一个指标所有对象都差不多：

p=(0.33,0.33,0.34)

非常均匀，那么：

e_j\rightarrow1

意味着：

\boxed{\text{熵高 → 数据均匀 → 区分能力弱}}

反之：

p=(0.8,0.15,0.05)

差异很大，那么：

e_j\rightarrow0

意味着：

\boxed{\text{熵低 → 数据差异大 → 区分能力强}}

---

# **7. Step 5：计算信息效用值** d_j

定义：

\boxed{ d_j=1-e_j }

其中：

d_j=\text{第 }j\text{ 个指标的信息效用值}

所以：

e_j\uparrow \Rightarrow d_j\downarrow

即：

数据越均匀 → 熵越大 → 信息效用越小。

反过来：

e_j\downarrow \Rightarrow d_j\uparrow

即：

数据差异越明显 → 熵越小 → 信息效用越大。

---

# **8. Step 6：计算最终权重** w_j

最后把所有指标的信息效用进行归一化：

\boxed{ w_j = \frac{d_j} {\displaystyle\sum_{j=1}^{m}d_j} }

注意这里求和符号变了。

之前计算熵：

\sum_{i=1}^{n}

是在**不同对象之间求和**。

现在计算权重：

\sum_{j=1}^{m}

是在**不同指标之间求和**。

例如：

d_1=0.2,\quad d_2=0.3,\quad d_3=0.5

那么：

w_1=\frac{0.2}{0.2+0.3+0.5}=0.2

w_2=0.3

w_3=0.5

最终：

\boxed{ w=(0.2,0.3,0.5) }

并且一定满足：

\boxed{ \sum_{j=1}^{m}w_j=1 }

---

# **9. ⭐ 熵权法完整逻辑链**

这一条最值得记：

\boxed{ \text{原始数据 }x_{ij} \rightarrow \text{正向化/标准化 }z_{ij} \rightarrow \text{比例 }p_{ij} \rightarrow \text{熵值 }e_j \rightarrow \text{信息效用 }d_j \rightarrow \text{权重 }w_j }

对应公式：

x_{ij}

↓

标准化

z_{ij}

↓

计算比例

\boxed{ p_{ij} = \frac{z_{ij}} {\sum_{i=1}^{n}z_{ij}} }

↓

计算第 j 个指标的熵

\boxed{ e_j = -\frac{1}{\ln n} \sum_{i=1}^{n} p_{ij}\ln p_{ij} }

↓

计算信息效用

\boxed{ d_j=1-e_j }

↓

计算权重

\boxed{ w_j = \frac{d_j} {\sum_{j=1}^{m}d_j} }
