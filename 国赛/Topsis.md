# **TOPSIS 前期数据处理：正向化 + 标准化**

## **1. TOPSIS 的基本目的**

TOPSIS 用于解决：

**多个评价对象 + 多个评价指标 → 综合评价并排序**

假设：

- 有 n 个评价对象
- 有 m 个评价指标

原始数据矩阵为：

X=(x_{ij})_{n\times m}

其中：

- i=1,\dots,n：第 i 个**评价对象（行）**
- j=1,\dots,m：第 j 个**评价指标（列）**
- x_{ij}：第 i 个对象在第 j 个指标上的原始值

TOPSIS 的前期数据处理主要分为：

\boxed{ 原始矩阵 \rightarrow ①\ 正向化 \rightarrow ②\ 标准化 \rightarrow 标准化矩阵Z \rightarrow 后续TOPSIS评价 }

---

# **2. Step 1：矩阵正向化**

## **为什么要正向化？**

不同指标对于“好”的定义可能不同：
TOPSIS 希望所有指标最终具有相同方向：

\boxed{\text{数值越大 = 表现越好}}

因此第一步就是**正向化（Forward Transformation）**。

---

## **2.1 极大型（效益型）指标**

特点：

\boxed{\text{越大越好}}

因为本身已经满足 TOPSIS 的要求，所以：

\boxed{\text{无需正向化}}

例如：

60,\ 80,\ 90

本身就是：

90最好>80>60

---

## **2.2 极小型（成本型）指标**

特点：

\boxed{\text{越小越好}}

例如：

- 成本
- 污染程度
- 死亡率
- 故障率
- 等待时间

一种常见的正向化方法：

\boxed{ \tilde{x}_i=\max_i(x_i)-x_i }

例如污染指数：

(20,50,80)

因为：

\max(x)=80

所以：

(20,50,80) \rightarrow (60,30,0)

原来的最小值 20 最好，转换以后变成最大值 60。

因此成功转换为：

\boxed{\text{越大越好}}

---

## **2.3 中间型指标**

特点：

\boxed{\text{越接近某个最佳值 }x_{\text{best}}\text{ 越好}}

例如：

最佳温度 = 25℃

首先计算每个值距离最佳值的距离：

|x_i-x_{\text{best}}|

然后找到最大距离：

M=\max_i|x_i-x_{\text{best}}|

正向化：

\boxed{ \tilde{x}_i = 1- \frac{|x_i-x_{\text{best}}|}{M} }

因此：

- 刚好等于最佳值 → \tilde{x}=1
- 越接近最佳值 → 越接近 1
- 离最佳值越远 → 越接近 0

核心思想：

\boxed{\text{离最佳点越近 → 正向化后的值越大}}

---

## **2.4 区间型指标**

特点：

\boxed{\text{落在最佳区间 }[a,b]\text{ 内最好}}

例如：

[20,25]^\circ C

都是最佳温度。

因此：

a\leq x_i\leq b

时：

\boxed{\tilde{x}_i=1}

如果落在区间外：

**离最佳区间越远 → 正向化后的值越小。**

因此中间型与区间型最大的区别：

\boxed{ \begin{aligned} \text{中间型}&：\text{离“最佳点”多远}\\ \text{区间型}&：\text{离“最佳区间”多远} \end{aligned} }

---

# **3. Step 1 总结：正向化到底在干什么？**

原始矩阵中可能同时存在：

\begin{cases} \text{越大越好}\\ \text{越小越好}\\ \text{接近某个值最好}\\ \text{处于某个区间最好} \end{cases}

经过正向化以后，全部统一为：

\boxed{\text{越大越好}}

所以：

**正向化解决的是“方向不同”的问题。**

注意：

\boxed{\text{正向化}\neq\text{把所有数据变成0～1}}

正向化的核心只是**统一方向**。
